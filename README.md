# site-valhalla-club

Repositório do site do Valhalla Clube de RPG de mesa.

## Aplicações

- `apps/web`: front-end em Next.js, TypeScript, Tailwind CSS e App Router.
- `apps/api`: API do projeto.

## Rodando o front-end

Instale as dependências e suba o servidor local:

```bash
cd apps/web
npm install
npm run dev
```

A aplicação fica disponível em `http://localhost:3000`.
